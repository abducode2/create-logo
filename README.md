# مشروع تحديث هوية النادي الرياضي (New Identity) 🛡️

واجهة ويب عصرية (Landing Page) مخصصة لاستعراض تحديث شعار نادي رياضي، تركز على تقديم الأفكار الإبداعية والخطوات العملية لإطلاق الهوية الجديدة بشكل احترافي.

## 🚀 المميزات
* **تصميم متجاوب:** متوافق تماماً مع جميع الشاشات (جوال، تابلت، حاسوب).
* **دعم الوضع الليلي (Dark Mode):** إمكانية التبديل بسلاسة بين الوضع الفاتح والمظلم.
* **تجربة مستخدم سلسة:** استخدام `scroll-smooth` للتنقل بين الأقسام.
* **واجهة عربية:** دعم كامل للكتابة من اليمين إلى اليسار (RTL) مع خط **Tajawal** الأنيق.
* **تفاعلية عالية:** تأثيرات حركية (Hover effects) وانتقالات ناعمة للعناصر.

## 🛠️ التقنيات المستخدمة
* **HTML5:** لهيكلة المحتوى.
* **Tailwind CSS:** للإطارات التصميمية والتنسيق السريع.
* **JavaScript:** للتحكم في وضع النظام (Theme Toggle) والوظائف التفاعلية.
* **Font Awesome:** للأيقونات الاحترافية.
* **Preline UI:** لمكونات واجهة المستخدم الجاهزة والمتوافقة مع Tailwind.
* **Google Fonts:** استيراد خط (Tajawal).

## 📂 هيكلة المشروع
* `index.html`: الملف الرئيسي الذي يحتوي على الهيكل، التنسيقات (Tailwind)، والسكربتات.
* **الأقسام الرئيسية:**
    1.  **Header:** شريط التنقل مع زر تبديل الوضع الليلي.
    2.  **Hero Section:** عرض عنوان التحديث مع صورة استباقية.
    3.  **Ideas Section:** عرض ثلاث استراتيجيات (المقارنة، سرد القصة، التحريك).
    4.  **Tools Section:** الأدوات المساعدة (Canva, Pinterest, Apps).
    5.  **Tips Section:** نصائح ذهبية لنجاح فيديو التدشين.
    6.  **Footer:** معلومات التواصل والحقوق.

## 💻 كيفية التشغيل
1. قم بتحميل الملف أو نسخ الكود الموجود في `index.html`.
2. افتح الملف باستخدام أي متصفح حديث (Chrome, Edge, Firefox).
3. لا يحتاج المشروع إلى تثبيت أي مكتبات محلياً، حيث يتم استدعاؤها عبر روابط CDN مباشرة.

## 🎨 التخصيص
يمكنك تعديل الألوان الأساسية للنادي من خلال تعديل قسم `tailwind.config` داخل ملف الـ HTML:
```javascript
colors: {
    brand: {
        500: '#22c55e', // اللون الأساسي
        600: '#16a34a', // الدرجة الأغمق
    }
}
```
